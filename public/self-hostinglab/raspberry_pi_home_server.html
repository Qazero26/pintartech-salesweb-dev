Pengenalan Hardware

Apa Itu Raspberry Pi?

Raspberry Pi ialah sebuah **Single-Board Computer (SBC)** bersaiz kad kredit yang lengkap dengan komponen komputer biasa.

Komponen Utama Hardware

  • CPU: ARM-based processor
  • RAM: 1GB - 8GB LPDDR4
  • Storage: microSD card / USB SSD
  • Network: Gigabit Ethernet & Wi-Fi
  • I/O: USB 3.0, HDMI, GPIO pins

Kegunaan Utama

✓ Learning & Linux
✓ Home Server
✓ Automation Lab
✓ Network Monitoring
✓ Small Web Apps
✓ IoT Projects
Kelebihan & Reality Check

Kenapa Guna Raspberry Pi?

Kelebihan Utama (Pros)

  • Saiz Fizikal Kecil: Senang disorok atau diletakkan di sebelah router.
  • Kuasa Sangat Rendah: Menggunakan 5W - 15W sahaja (murah bil elektrik 24/7).
  • Pengoperasian Senyap: Tiada bunyi bising fan pelayan enterprise.
  • Ekosistem Linux Mantap: Sokongan komuniti luas & OS stabil.

Peringatan Penting

Raspberry Pi tidak sesuai untuk semua jenis tugas (workload heavy).

⚠️ Tidak digalakkan untuk video transcoding 4K berat, database korporat raksasa, atau trafik jutaan penggunan serentak.

Raspberry Pi Bukan Magic!

Membeli Raspberry Pi tidak secara automatik menjadikan anda mempunyai server yang siap pakai.

Pemilihan Storage

Storage: microSD vs SSD

🎴

microSD Card

  • Sangat mudah & murah untuk bermula
  • Cukup baik untuk projek pembelajaran awal
  • Ketahanan rendah pada penulisan data kerap (write cycles)
  • Berisiko corrupt jika sudden power outage
💽

External USB SSD

  • Kelajuan read/write berlipat ganda jauh lebih pantas
  • Sangat tahan lama untuk heavy Docker / Database workload
  • Sesuai untuk perkhidmatan jangka panjang
  • Memerlukan kabel adapter USB3-to-SATA yang sesuai
Kestabilan Bekalan Kuasa

Power & Integrity System

Server memerlukan bekalan kuasa (power supply) yang **konsisten dan stabil 24/7**.

Kesan Power Drops / Cable Lemah

  • • Sudden Shutdown / Under-voltage throttling
  • • Filesystem corruption (Kerosakan sistem fail)
  • • Data loss pada database / logs
  • • Service interruption tidak dijangka

Best Practices Bekalan Kuasa

  • ✓ Guna Power Supply Rasmi Raspberry Pi (5V 3A+)
  • ✓ Elakkan guna charger phone murahan/lama
  • ✓ Pertimbangkan mini-UPS / Powerbank pass-through jika perlu
Sistem Operasi

Operating System: Raspberry Pi OS

Raspberry Pi OS (Lite 64-bit) ialah OS rasmi berasaskan Debian Linux yang dioptimumkan khusus untuk Raspberry Pi.

Applications / Containers (Docker, Python, NGINX)
Linux Kernel (Debian Core System)
Raspberry Pi Hardware (ARM Architecture)

*Gunakan versi **Lite (without desktop)** untuk kegunaan server kerana ia lebih ringan dan menjimatkan penggunaan RAM.

Headless Setup Concept

Headless bermaksud Raspberry Pi dikendalikan tanpa monitor, papan kekunci, atau tetikus secara terus.

Aliran Kerja Setup

Langkah Flashing & Configuration

1 Muat turun Raspberry Pi Imager pada laptop.
2 Pilih OS: Raspberry Pi OS Lite (64-bit).
3 Konfigurasi OS Customisation (Hostname: raspberrypi, User: <USERNAME>).
4 Aktifkan SSH & masukkan Wi-Fi credential / LAN setup.
5 Flash ke microSD / SSD -> Masukkan ke Pi -> Cucuk Power & Network.
Penemuan Rangkaian

First Boot & Cari IP Address

Selepas menyalakan Raspberry Pi, kita perlu mencari **Private IP Address** yang diberikan oleh Router.

Cara Mencari IP Raspberry Pi:

  • Semak senarai DHCP Client List di Dashboard Router (cth: 192.168.1.1).
  • Guna command ping: ping raspberrypi.local
  • Guna scanner app seperti Fing atau nmap.
# Contoh IP yang dijumpai: 192.168.1.50
ssh <USERNAME>@192.168.1.50
Remote Access

Sambungan SSH Pertama

Buka Terminal (Linux/Mac) atau PowerShell/Command Prompt (Windows) dan mulakan sambungan SSH.

Terminal - ssh piuser@192.168.1.50
$ ssh <USERNAME>@192.168.1.50
<USERNAME>@192.168.1.50's password: **********

Linux raspberrypi 6.1.0-rpi7-2712 #1 SMP PREEMPT Debian 12.5-1
<USERNAME>@raspberrypi:~$ _

Tahniah! Anda kini berhubung terus ke terminal sistem operasi Linux di Raspberry Pi.

Strategi IP Address

Static IP vs DHCP Reservation

Option A: Static IP Pada Host

Ditentukan secara manual dalam fail konfigurasi Linux Raspberry Pi (cth: /etc/dhcpcd.conf atau NetworkManager).

• Boleh berlaku konflik IP jika router memberikan IP yang sama kepada peranti lain.

Option B: DHCP Reservation (Disyorkan)

Dikonfigurasi di dalam Router Settings. Router mengunci MAC Address Raspberry Pi supaya sentiasa mendapat IP yang sama.

✓ Paling selamat, tersusun & mengelakkan isu IP conflict!
Penyelenggaraan

Kemaskini Sistem Sistem (Update)

Sentiasa pastikan senarai pakej dan aplikasi Linux anda mendapat security patch terkini.

# 1. Muat turun senarai senarai pakej terkini daripada server Debian
sudo apt update
# 2. Pasang (install) semua kemaskini sekuniti & perisian
sudo apt upgrade -y
💡 Tip: apt update hanya mengemaskini indeks/senarai. apt upgrade yang melakukan pemasangan sebenar.

Aplikasi Pertama

Menjalankan Python Web Server

Gunakan modul bawaan Python untuk menguji fungsi server dengan pantas:

# Masukkan HTML ringkas
echo "<h1>Hello World dari Raspberry Pi!</h1>" > index.html

# Jalankan Python HTTP Server pada Port 8080
python3 -m http.server 8080 --bind 0.0.0.0

Parameter --bind 0.0.0.0 memastikan server menerima sambungan daripada semua peranti dalam LAN.

Ujian LAN

Ujian Rangkaian Tempatan (Local Test)

Buka pelayar web (Browser) di laptop atau telefon bimbit yang menyertai Wi-Fi/LAN yang sama:

URL Pelayar Web: http://192.168.1.50:8080

Jika paparan "Hello World dari Raspberry Pi!" keluar, ini mengesahkan **Local Web Server** anda telah berjaya berfungsi!

Keselamatan Rangkaian

Security Sebelum Terhubung Ke Internet

Jangan sewenang-wenangnya membuka server ke Internet tanpa kawalan firewall (UFW):

# Pasang UFW (Uncomplicated Firewall)
sudo apt install ufw -y

# Benarkan SSH (Sangat Penting! Elak terputus akses)
sudo ufw allow ssh

# Benarkan port app sahaja
sudo ufw allow 8080/tcp

# Aktifkan Firewall
sudo ufw enable

Public Access

Sambung Ke Internet: Cloudflare Tunnel

Cara Lama (Port Forwarding)

  • ❌ Perlu Public IP router
  • ❌ Buka Port Router ke internet (Berisiko tinggi)
  • ❌ Terdedah serangan DDoS terus ke rumah

Cara Baru (Cloudflare Tunnel)

  • ✓ Hanya perlukan Outbound Connection
  • ✓ Tiada sebarang Port Forwarding dibuka
  • ✓ Dilindungi oleh Firewall Cloudflare & HTTPS percuma

Pengukuhan Akses

SSH Security Best Practices

✓ Gunakan SSH Key Authentication

Gantikan kata laluan biasa dengan SSH Public/Private key pair.

✓ Matikan Password Authentication

Tetapkan PasswordAuthentication no dalam /etc/ssh/sshd_config.

✓ Nyahaktifkan Login Root Direct

Tetapkan PermitRootLogin no.

✓ Hadkan Port Pengurusan

Jangan sekali-kali expose port SSH (22) secara terus ke Internet.

Prinsip Keselamatan

Pengurusan Pengguna & Least Privilege

Prinsip Hak Akses Minimum (Least Privilege)

Jangan sesekali menjalankan perkhidmatan aplikasi web terus sebagai akaun root. Jika aplikasi tersebut diceroboh, penceroboh akan mendapat kawalan penuh ke atas seluruh OS server!

❌ Guna root untuk jalankan script/app biasa
✓ Guna akaun biasa + sudo jika diperlukan
Pengurusan Maklumat Sulit

Secrets Management

Dilarang Sama Sekali (DON'T)

  • ❌ Simpan API Key/Password dalam kod source
  • ❌ Commit fail credential ke GitHub Public Repo
  • ❌ Simpan Cloudflare Token dalam fail awam

Cara Betul (DO)

  • ✓ Guna Environment Variables (fail .env)
  • ✓ Masukkan .env dalam .gitignore
  • ✓ Guna Docker Secrets / Encrypted storage

Suhu Hardware

Suhu & Throttling Raspberry Pi

Apabila suhu CPU melebihi **80°C**, Raspberry Pi akan mengalami Thermal Throttling (perlahankan prestasi automatik).

# Semak suhu CPU Raspberry Pi secara terus
vcgencmd measure_temp
temp=46.2'C
Penyelesaian Penjagaan Suhu: Gunakan casing aluminium dengan passive cooling heatsink atau kipas angin mini (active fan).
Kapasiti Storage

Pemantauan Ruang Storage

$ df -h /
Filesystem Size Used Avail Use% Mounted on
/dev/mmcblk0p2 29G 8.5G 19G 32% /

⚠️ Risiko Jika Disk Full (100% Used):

  • Aplikasi & Database gagal menulis data baharu
  • Docker Container mengalami crash atau restart loop
  • Sistem Linux gagal boot semula dengan sempurna

Kebergantungan Rangkaian

Kebergantungan Sambungan Internet

Apabila talian Internet rumah terputus (Internet Down):

✅ Local Network (LAN)

Masih berfungsi! Anda masih boleh akses Raspberry Pi melalui IP Tempatan (192.168.1.50).

❌ Public Access (Cloudflare Tunnel)

Terputus! Akses awam luar tidak boleh sampai ke rumah sehingga Internet pulih.

Senario Gangguan Kuasa

Senario Terputus Elektrik & Pemulihan

1. Elektrik Terputus -> Raspberry Pi Mati Mendadak
2. Elektrik Pulih -> Raspberry Pi Menyala (Auto Boot)
3. Docker Service Bermula Automatik (Restart Policy)
4. Cloudflare Tunnel Sambung Semula Outbound
5. Website Kembali Live Ke Seluruh Dunia!
Auto-Recovery

Self-Healing Basics

Pastikan perkhidmatan bangkit semula secara automatik selepas reboot tanpa campur tangan manual:

# Gunakan Docker Restart Policy
docker run -d --restart always myapp
# Atau dalam docker-compose.yml
restart: unless-stopped
