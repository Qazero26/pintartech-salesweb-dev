SLIDE 02 — HARI PERTAMA DEVELOPER

Kita Bermula Dengan Localhost

Bayangkan anda baru siap membina sebuah Python Web Server pada komputer Windows anda:

Command Prompt / PowerShell
python -m http.server 8080 --bind 0.0.0.0
Local URL Server Anda:
http://localhost:8080
  • Python sedang me-run sebuah web server secara lokal.
  • Server ini hidup & berjalan hanya pada komputer anda.
  • Port yang digunakan ialah 8080.

SLIDE 05 — PENGENALAN

Apa Itu Ngrok?

"ngrok ialah platform yang menyediakan secure tunnels untuk menghubungkan local service (pada komputer anda) kepada Internet secara selamat."
Analogi Mudah:
🏠 Localhost = Bilik Dalam Rumah Semua barang ada di dalam bilik anda, tetapi pintu rumah bertutup rapat dari luar.
🚇 ngrok = Tunnel Selamat Laluan khas (tunnel) yang menghubungkan bilik anda terus ke stesen luar tanpa perlu membuka pintu utama rumah.

SLIDE 06 — RAHSIA TEKNIKAL #1

Kenapa Tak Perlu Public IP Rumah?

Biasanya, untuk membenarkan akses luar masuk, anda memerlukan Public IP static dari ISP. Namun dengan ngrok, peranti anda yang memulakan sambungan ke luar (Outbound).

Cara Tradisional (Inbound Direct)

Internet → Public IP → Router → Port Forwarding → Server

Memerlukan pendedahan Public IP rumah secara langsung kepada ancaman imbasan Internet.

Cara Ngrok (Outbound Tunnel)

Server Local → Connection KELUAR → ngrok Cloud

Server membuat sambungan selamat ke awan ngrok, mengelakkan keperluan mendedahkan Public IP rumah.

📌 Nota Penting: Sambungan rumah masih mempunyai IP awam dari ISP, tetapi aplikasi tempatan anda tidak perlu didedahkan melalui IP awam rumah atau inbound port forwarding!
SLIDE 07 — RAHSIA TEKNIKAL #2

Kenapa Tak Perlu Port Forwarding?

Perbandingan Aliran Trafik:

1. Port Forwarding Biasa (Rumit & Berisiko)
Internet Router House Buka Port (8080) Server Local
2. Menggunakan ngrok Tunnel (Pantas & Selamat)
Server Local ngrok agent ngrok Cloud Internet
Mengapa ini berlaku? Kerana firewall router membenarkan peranti tempatan membuat sambungan Outbound (keluar) secara lalai. Local agent menumpangkan data inbound di dalam saluran tunnel outbound tersebut.
SLIDE 08 — KOMPONEN UTAMA

Apa Itu Ngrok Agent?

ngrok agent ialah aplikasi kecil (binary/executable) yang berjalan pada komputer atau server tempatan anda.

1
Sambung ke ngrok Membuka sambungan TLS selamat ke pelayan ngrok Cloud.
2
Membina Tunnel Menghubungkan sesi unik komputer anda dengan URL awam.
3
Menerima Trafik Mendengar sebarang request daripada ngrok Cloud melalui tunnel.
4
Forward Traffic Menghantar request tersebut ke local application (Python :8080).
ngrok Cloud ngrok Agent localhost:8080
SLIDE 09 — LANGKAH 1

Install Ngrok Pada Windows

Muat turun ngrok untuk Windows dari laman rasmi atau guna pakej manager (Chocolatey / Winget / direct zip).

Semak Pemasangan Melalui Command Prompt:
ngrok version
Jika anda meletakkan `ngrok.exe` terus dalam folder projek:
ngrok.exe version
Gunakan kaedah atau arahan yang paling sesuai dengan versi dan persekitaran OS anda.
SLIDE 10 — LANGKAH 2

Login & Konfigurasi Authtoken

Untuk keselamatan dan membuka kunci ciri tunnel, ngrok memerlukan token pengesahan (Authtoken) daripada akaun percuma anda.

Sediakan Token (Gantikan <TOKEN> dengan token anda)
ngrok config add-authtoken <TOKEN>
AMARAN KESELAMATAN PENTING:

Jangan sesekali berkongsi Authtoken anda kepada orang lain! Token ini ialah credential sulit yang mengesahkan identiti akaun anda pada pelayan ngrok.

SLIDE 16 — SEKURITI ASAS

Public HTTPS vs Local HTTP Origin

ngrok secara automatik menyediakan TLS/SSL Certificate untuk endpoint awam anda:

HTTPS (Ter-enkripsi)
Internet → ngrok Cloud
HTTP (Tempatan)
ngrok Agent → localhost:8080
Public connection & local origin ialah dua bahagian berbeza. Anda tidak perlu pening menguruskan SSL Certificate pada Python server tempatan anda.

SLIDE 21 — CONTOH IMPAK

Kenapa Webhook Perlukan Ngrok?

❌ TANPA NGROK

Stripe / Telegram send HTTP callback ke `http://localhost:8080/webhook`.

Failed! Localhost tak boleh dicapai dari luar server Stripe.
✅ DENGAN NGROK

Stripe send callback ke `https://<NGROK-URL>/webhook`.

Success! ngrok forward request terus ke local Python server!

SLIDE 28 — PERTIMBANGAN NGROK

Kekangan Umum Ngrok

• Ciri lanjutan (seperti custom domain kekal) bergantung kepada pelan dan akaun semasa.
• Public URL percuma bersifat sementara mengikut sesi tunnel.
• Had bandwidth dan permintaan dikawal mengikut struktur akaun semasa.
SLIDE 29 — KEKUATAN CLOUDFLARE

Kelebihan Cloudflare Tunnel

Integrasi terus dengan Domain DNS Cloudflare anda sendiri.
Disepadukan dengan ekosistem Cloudflare Zero Trust & Access Control.
Sangat sesuai untuk hosting aplikasi pelayan rumah (Home Server / Homelab).
SLIDE 30 — CABARAN CLOUDFLARE

Kekangan Cloudflare Tunnel

• Persediaan awal memerlukan domain berdaftar dan pengurusan DNS Cloudflare.
• Kurang praktikal jika anda hanya ingin testing ad-hoc 5 minit tanpa domain.
• Memerlukan kefahaman dashboard Cloudflare Zero Trust yang lebih kompleks.
