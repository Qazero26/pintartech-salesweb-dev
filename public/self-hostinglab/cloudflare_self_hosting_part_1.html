Slide 04

Dua Cara Yang Berbeza

Perbandingan senbina Direct Public IP vs Cloudflare Tunnel.

❌ CARA TRADISIONAL

Inbound Open Port

Internet

└─► Public IP (Kena ada static IP)

    └─► Router Home/Office

        └─► ⚠️ Port Forwarding (80/443)

            └─► Local Server

Perlu dedahkan router kepada serangan luar (Inbound Open Port).

✅ CARA CLOUDFLARE TUNNEL

Outbound Only

Internet

└─► Cloudflare Network

    └─► Secure Encrypted Tunnel

        └─► cloudflared (Outbound)

            └─► Local Server

Hanya buat outbound connection. Router kekal tertutup rapat!

🌟 Highlight Utama:

"Untuk Tunnel, kita tidak perlu membuka inbound port pada router." Cloudflare Tunnel menggunakan connection outbound daripada cloudflared ke Cloudflare.

Slide 06

Apa Itu Cloudflare Tunnel?

Jambatan terowong berasaskan perisian untuk keselamatan maksimum.

Cloudflare Tunnel ialah sambungan terenkripsi yang menghubungkan server/komputer local kita secara langsung ke rangkaian global Cloudflare.

cloudflared
Aplikasi ringan (daemon) yang dipasang pada PC/server korang.
Outbound Daemon
💻 Server Tempatan
── outbound connection ──►
☁️ Cloudflare

📌 Perkara Penting:

"Server kita yang membuat connection keluar." cloudflared memulakan sambungan dari dalam ke luar, jadi firewall tak akan menyekatnya!

Slide 07

Analogi Mudah (Rumah & Pagar)

Bagaimana Tunnel mengubah cara tetamu masuk ke rumah anda.

🏠 Cara Public IP + Port Forward

1. Orang luar tanya alamat rumah (Public IP).

2. Orang luar berjalan sampai depan pagar (Router).

3. Pagar rumah dibuka kekal 24 jam (Port Forwarding).

4. Orang terus masuk ke bilik server.

⚠️ Berisiko: Semua orang tahu alamat fizikal rumah & pintu sentiasa terbuka.

🚇 Cara Cloudflare Tunnel

1. Server rumah gali terowong rahsia dari dalam keluar ke pejabat Cloudflare.

2. Orang luar hanya jumpa pejabat Cloudflare.

3. Cloudflare tapis orang luar & hantar melalui terowong rahsia.

✅ Selamat: Orang luar tak tahu alamat rumah & pagar rumah berkunci rapat!

"Cloudflare Menjadi Pintu Hadapan Utama!"

Slide 08

Apa Itu `cloudflared`?

Agen perisian penting yang dipasang pada komputer/server tempatan.

cloudflared ialah program perisian CLI ringkas daripada Cloudflare. 4 Fungsi Utamanya:

1. 🔗 Connect: Sambung secara selamat ke rangkaian Cloudflare Edge.
2. 🔄 Kekalkan Tunnel: Re-connect automatik jika internet terputus.
3. 📥 Terima Traffic: Menyambut data web request daripada Cloudflare.
4. ⏩ Forward Traffic: Salurkan request ke local app (port 8080).
☁️ Cloudflare Network
│ ⬇️ Tunnel Request
🚇 cloudflared CLI
│ ⬇️ Local Forward
💻 localhost:8080

Slide 28

Apa Yang Berlaku Sebenarnya?

Langkah demi langkah kitaran hayat data (Request & Response Lifecycle).

1. User buka: https://app.domainbos.com
2. DNS membawa hostname kepada Cloudflare/Tunnel.
3. Cloudflare menerima request di Edge Network.
4. Cloudflare hantar request melalui terowong outbound tunnel.
5. cloudflared pada PC menerima request.
6. cloudflared forward ke http://localhost:8080.
7. Python Web Server memproses & beri jawapan.
8. Response kembali melalui tunnel ke Cloudflare.
9. User menerima paparan webpage dengan selamat.
