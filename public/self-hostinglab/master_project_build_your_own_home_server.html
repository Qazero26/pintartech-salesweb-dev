PHASE 2

Operating System Setup

Raspberry Pi → Storage → Raspberry Pi OS → Linux

Foundation Of The Server

Operating System (OS) ialah asas utama (foundation) untuk semua perkhidmatan dan container yang akan dijalankan selepas ini. Kita menggunakan Raspberry Pi OS (Lite 64-bit) berasaskan Debian Linux untuk prestasi optimum tanpa GUI bebanan tambahan.

Headless Server Concept

Menjalankan server tanpa monitor atau papan kekunci luaran

Raspberry Pi
← Network →
Laptop / PC
  • Mode Server Sebenar: Server pengeluaran jarang dipasang monitor atau tetikus.
  • Pengurusan Jarak Jauh: Konfigurasi Wi-Fi/Ethernet dan SSH diaktifkan semasa proses flashing OS menggunakan Raspberry Pi Imager.
PHASE 3

Network Setup (LAN)

Router
192.168.1.1
─────── LAN ───────
Raspberry Pi
192.168.1.50

Raspberry Pi memerlukan IP address tempatan (Private IP) yang konsisten supaya SSH dan pengurusan LAN tidak terputus.

Pilihan A: DHCP Reservation

Ditetapkan melalui Settings Router berdasarkan MAC Address Raspberry Pi.

Pilihan B: Static IP

Ditetapkan secara terus dalam konfigurasi network OS Raspberry Pi (dhcpcd / NetworkManager).

Ujian Rangkaian LAN

Perintah asas Linux untuk menyemak status networking:

Terminal Shell 
hostname
hostname -I
ip addr
ip route
Matlamat: "Raspberry Pi boleh berkomunikasi secara stabil dalam Local Area Network (LAN)."
PHASE 4

SSH Access Setup

Sambungan dari Laptop:
ssh <USERNAME>@192.168.1.50
Laptop ━━ Secure Shell (SSH Port 22) ━━► Raspberry Pi

Sekarang server anda boleh diurus dan dikawal dari jauh melalui baris perintah CLI secara selamat!

SSH Security Best Practices

SSH Key Authentication

Gunakan RSA/Ed25519 key pair dan nyahdayakan password login.

Least Privilege

Elakkan menggunakan akaun root secara terus untuk aktiviti harian.

Software Updates

Pastikan OpenSSH daemon dan sistem senantiasa dikemaskini.

Avoid Exposure

Jangan sesekali buka Port 22 terus ke public Internet.

⚠️ PENTING: Gunakan credential placeholder dalam dokumentasi dan elakkan mendedahkan Private Keys!

Kemaskini Sistem Operasi

Sentiasa update sistem Linux sebelum memasang aplikasi utama:

APT Package Manager 
sudo apt update
sudo apt upgrade -y

Python App (app.py)

Aplikasi Flask/HTTP ringkas mendengarkan pada 0.0.0.0:8080

from flask import Flask
app = Flask(__name__)

@app.route('/')
def home():
    return "Hello from Raspberry Pi Home Server!"

@app.route('/health')
def health():
    return {"status": "healthy"}, 200

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=8080)

Dockerfile Configuration

FROM python:3-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
CMD ["python", "app.py"]
1. Base Image
2. Working Dir
3. Dependencies
4. Startup Command

Bina Docker Image

Source Code → Dockerfile → Docker Image → Container
Perintah Build:
docker build -t myapp .

Jalankan Container

docker run -d \
  --name myapp \

Database Isolation

🔒 Private Network Isolation
Python Web App ──► Private Container Network ──► Database Container

Database TIDAK didedahkan secara terus ke Internet. Akses hanya dibenarkan dari bekas container aplikasi web sahaja.

Persistent Storage (Docker Volumes)

docker run -d \
  -v app_data:/app/data \
  --name myapp myapp

Data dipisahkan daripada kitaran hayat container. Walaupun container dimusnahkan dan dibina semula, data penting tetap tersimpan selamat.
