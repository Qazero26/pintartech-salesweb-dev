Konsep Asas #1

Apa itu Web Server?

Program Yang Sentiasa Memerhati

Web server bukanlah kotak besi besar sahaja. Ia sebenarnya adalah sebuah program/perisian yang berjalan dan sentiasa "menunggu request" (permintaan) daripada pelayar web (browser).

Python Sebagai Server Latihan

Dalam latihan ini, kita menggunakan Python. Python sudah ada modul khas built-in untuk menghidangkan fail website (seperti index.html) kepada browser tanpa memerlukan persediaan rumit.

Komputer Windows Anda

menjalankan
Python Server
PORT 8080
index.html
Langkah Praktikal #1

Mulakan Python Server

Buka Terminal atau Command Prompt (CMD) di Windows anda, pergi ke folder fail web anda, dan taip arahan berikut:

Command Prompt / PowerShell 
python -m http.server 8080 --bind 0.0.0.0
8080

Nombor Port

Pintu khas yang dibuka pada komputer untuk trafik HTTP latihan ini.

--bind 0.0.0.0

Semua Interface

Mengarahkan server menerima sambungan dari mana-mana Kad Rangkaian (Wi-Fi/LAN).

Latihan Sahaja

Bukan Production

Server mudah ini sesuai untuk belajar & ujian tempatan sahaja.

# Output contoh yang akan kelihatan di terminal:
Serving HTTP on 0.0.0.0 port 8080 (http://0.0.0.0:8080/) ...
Konsep Asas #2

Apa itu Localhost?

Analogi Mudah

"Localhost bermaksud komputer itu sendiri."
Sama seperti perkataan "Saya" merujuk kepada diri anda sendiri, localhost ialah nama cermin bagi komputer tersebut.

Alamat URL di pelayar web:
http://localhost:8080
atau menggunakan IP Loopback: http://127.0.0.1:8080

PENTING UNTUK DIINGAT:

  • localhost BUKAN Internet.
  • localhost BUKAN Public IP.
  • Ia HANYA boleh dipanggil dari dalam mesin yang sama!

Aliran Akses Localhost

Browser (Chrome/Edge)
panggil localhost:8080
Komputer Windows Anda
hantar ke program
Python Server (Port 8080)
Ujian Praktikal #1

Ujian Localhost

Langkah-langkah Ujian:

  1. 1 Pastikan Python server sedang dijalankan di Terminal.
  2. 2 Buka web browser di komputer Windows server tersebut.
  3. 3 Taip alamat URL: http://localhost:8080
  4. 4 Paparan fail / laman index.html kelihatan.

Kesimpulan Ujian

"Server HIDUP dan berjaya dicapai dari dalam komputer sendiri!"

Masalah Pertama

Kenapa Localhost Tak Cukup?

Bayangkan anda ambil telefon bimbit anda, buka browser, dan taip:

http://localhost:8080

Apa yang berlaku? Telefon akan mencari web server pada telefon itu sendiri! Ia tidak akan menjumpai Python server di komputer Windows anda.

Setiap peranti mentafsirkan perkataan "localhost" sebagai "dirinya sendiri".

localhost:8080 Python Server
Telefon Bimbit
localhost:8080 ❌ Tiada Server
Konsep Asas #3

Apa itu Private IP?

Alamat Dalam Rangkaian Rumah (LAN)

Private IP ialah alamat unik yang diberikan oleh Wi-Fi Router kepada setiap peranti dalam rumah anda (PC, telefon, TV pintar, laptop).

Contoh Format Private IP:
192.168.1.50
(Boleh jadi 192.168.0.X atau 10.0.0.X bergantung pada router)

Cara Semak Di Windows

Buka CMD / PowerShell dan taip:

ipconfig

Cari maklumat di bahagian IPv4 Address:

IPv4 Address. . . . . . . . . . . : 192.168.1.50
Perbandingan Pintar

Localhost vs Private IP

LOCALHOST

127.0.0.1 / localhost

Merujuk terus kepada komputer itu sendiri sahaja.

http://localhost:8080
→ Dibuka dari Windows sendiri
PRIVATE IP

192.168.1.50

Merujuk kepada komputer dalam rangkaian rumah (Wi-Fi/LAN).

http://192.168.1.50:8080
→ Boleh dipanggil dari telefon dalam Wi-Fi sama
Langkah Praktikal #2

Akses Dari Telefon Bimbit

Jika Telefon Bimbit dan Komputer Windows berada dalam Wi-Fi rumah yang sama, telefon kini boleh cuba mengakses server anda!

Buka Safari / Chrome di Telefon dan taip:
http://192.168.1.50:8080
* Gantikan 192.168.1.50 dengan alamat Private IP komputer Windows anda yang didapati daripada ipconfig.

Troubleshooting

Kenapa Tak Boleh Akses?

Jika telefon keluar ralat "Connection Timed Out", semak senarai ini terlebih dahulu!

1

Windows Firewall Block Port

Secara lalai, Windows menghalang sebarang sambungan luar yang cuba masuk ke port 8080.

2

Network Tidak Sama

Telefon guna Mobile Data 4G/5G atau tersambung pada Wi-Fi Jiran / Wi-Fi berbeza.

3

Python Server Terhenti

Terminal Python tertutup atau terbatal secara tidak sengaja.

4

AP Isolation Pada Router

Fungsi keselamatan router yang menghalang peranti Wi-Fi daripada berkomunikasi sesama sendiri.

💡 Pesanan Penting: Jangan terus membuat andaian masalah ini disebabkan oleh Port Forwarding. Selesaikan perisai Firewall terlebih dahulu!
Keselamatan Windows

Windows Firewall

Windows Firewall berfungsi sebagai pengawal peribadi. Kita perlu beri kebenaran khas untuk benarkan trafik masuk menerusi TCP Port 8080.

Buka PowerShell (Run as Administrator) & Taip Arahan Ini:
New-NetFirewallRule -DisplayName "Python Test 8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow
-Direction Inbound

Kebenaran untuk trafik sambungan yang datang dari Luar Masuk Ke Dalam PC.

-Protocol TCP

Protokol komunikasi berasaskan web standar.

-LocalPort 8080

Port spesifik tempat Python server kita sedang menunggu.

Konsep Asas #4

Apa itu Public IP?

Identiti Di Alam Internet

Public IP ialah alamat IP tunggal yang diberikan oleh Penyedia Perkhidmatan Internet (ISP seperti TM Unifi, Maxis, Time) kepada router rumah anda.

Analogi Mudah Bangunan:

🏢 Private IP = Nombor bilik/bilik tidur di dalam rumah (Contoh: Bilik 192.168.1.50)
📫 Public IP = Alamat Poskod luar rumah yang digunakan oleh Posmen (Contoh: 203.xxx.xxx.xxx)
Contoh Format Public IP
203.106.55.120

(Semua peranti di dalam rumah anda berkongsi SATU Public IP yang sama apabila melayari internet)

Perbandingan Utama

Private IP vs Public IP

PRIVATE IP

192.168.1.50
  • Digunakan khas dalam rangkaian dalaman rumah (LAN).
  • Diberikan secara automatik oleh Wi-Fi Router.
  • TIDAK Boleh dicapai secara terus dari Internet luar.
  • Percuma dan boleh sama dengan jiran sebelah rumah.

PUBLIC IP

203.xxx.xxx.xxx
  • Digunakan untuk komunikasi dengan seluruh dunia / Internet.
  • Diberikan oleh pembekal internet (ISP).
  • Unik di seluruh dunia (tiada orang lain yang guna IP sama).
  • Boleh dicapai oleh sesiapa sahaja di Internet.
Peranti Utama

Peran Router (Wi-Fi Modem)

Router adalah jambatan atau penjaga pintu (*gateway*) yang menghubungkan rangkaian dalaman rumah anda ke dunia luar (Internet).

Router mempunyai 2 muka:
1. Muka Luar (WAN) Memegang Public IP
2. Muka Dalam (LAN) Memegang Private IP
INTERNET LUAR
ROUTER RUMAH
Menyambung Public IP ↔ Private IP
📱 Telefon 💻 Laptop 🖥️ Windows Server
Kemuncak Masalah

Masalah Yang Kita Ada

Apabila seseorang dari Internet cuba membuka Public IP anda:

http://PUBLIC-IP:8080

Isyarat data berjaya sampai ke Router Rumah anda. TETAPI... Router keliru dan bertanya:

"Request port 8080 ini patut aku hantarkan kepada peranti yang mana satu di dalam rumah?" 🤔
Pelawat Dari Internet
ROUTER RUMAH
❓ PC Windows (192.168.1.50)
❓ Telefon
❓ TV

Tanpa arahan khas, Router akan membuang (drop) request tersebut demi keselamatan.

Solusi Utama

Apa itu Port Forwarding?

Definisi Mudah:

Port Forwarding ialah arahan tetap yang ditulis di dalam tetapan Router:
"Jika ada pelawat luar datang melalui Port 8080, terus hantar data itu ke Komputer Windows (192.168.1.50) pada Port 8080!"

PUBLIC IP
203.xxx.xxx.xxx:8080
ROUTER
Port Forwarding
WINDOWS
192.168.1.50:8080
PYTHON
Web Server
Konfigurasi Router

Contoh Setting Port Forwarding

Buka Dashboard Admin Router anda (selalunya http://192.168.1.1) & isi borang ini:

Protocol: TCP
External / WAN Port: 8080
Internal / LAN IP: 192.168.1.50
Internal / LAN Port: 8080

⚠️ Peringatan: Pastikan Internal IP di atas digantikan dengan Private IP komputer anda yang sebenar.

Soalan Lazim Beginner

Kenapa Guna Port Yang Sama?

External Port (8080) = Internal Port (8080)

Adakah External Port & Internal Port wajib sama? Tidak semestinya!

Router membenarkan anda memetakan port berbeza (contohnya External 80 → Internal 8080). Namun, untuk peringkat beginner, menggunakan nombor port yang sama (8080) memudahkan kita memahami aliran tanpa kekeliruan.

Laluan Permintaan Sambungan:
PUBLIC-IP : 8080
192.168.1.50 : 8080
Ujian Penentu

Test Dari Luar (Mobile Data)

SYARAT UJIAN PENTING:

JANGAN guna Wi-Fi rumah semasa melakukan ujian Public IP ini! Matikan Wi-Fi telefon bimbit anda dan gunakan MOBILE DATA (4G/5G).

Langkah Ujian:

  1. Cari Public IP anda di Google (taip: "what is my ip").
  2. Matikan Wi-Fi telefon bimbit (hidupkan Mobile Data).
  3. Buka browser telefon dan taip:
    http://PUBLIC-IP:8080
Kenapa Perlu Mobile Data?

Sebab kita mahu menguji laluan trafik Internet sebenar dari luar bangunan rumah masuk melalui Router ke PC anda.

Kejayaan Utama!

Jika halaman laman web Python anda berjaya dipaparkan di telefon bimbit yang menggunakan Mobile Data, anda telah rasmi berjaya meng-host web server sendiri dari rumah!
